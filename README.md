> **“推石上山的过程本身，就足以充实人的心灵。”**

这是一个基于 **Vibe Coding** 理念构建的交互式个人门户。它不仅是代码的堆叠，更是一场关于产业经济学逻辑与 AI 原生产品力探索的数字奥德赛。

---

## 🪐 核心叙事 

项目视觉与结构严格对应 Sisyphus 的四个哲学阶段，将个人成长路径结构化呈现：

* 攀登 ：积淀原始执行力。涵盖大型活动统筹与 MVP 商业模型的早期构建，展现从零到一的推动力。
* 登顶 ：以产业经济学为底座。通过量化实证 与 SCP 范式透视复杂业务系统，建立商业直觉。
* 坠落 ：技术重构与敏捷开发。利用大模型完成从 PRD 到交互原型的全栈闭环，探索 AI 在代码工程中的边界。
* 重生 ：推翻重来后的进化。专注于 AI Agent 架构与生成式交互的深度实践，寻找更纯粹的攀登路径。

---

## 🛠️ 技术栈 

作为一名 **AI 产品构建者**，本项目采用了 AI 原生驱动的开发范式：

* **交互引擎**：原生 HTML5 + JavaScript (ES6+)，利用现代 CSS `backdrop-filter` 打造沉浸式毛玻璃质感。
* **镜头控制**：封装自定义 `Cinematic Shots` 逻辑，通过滚动监听实现多维背景缩放与位移，强化叙事感。
* **开发流**：深度集成 **Cursor** 与 **Windsurf**，实践“自然语言即代码”的 Vibe Coding 模式。
* **逻辑底座**：融入产业经济学结构化思维，将复杂的个人经历转化为模块化的数字资产。

---

## 🏗️ 重点实验室 

在网站中重点展示了以下 AI 实践与实证研究：

1. **管理app**：基于 Gemini 与 cursor 开发的时间管理app，对碎片化时间和知识进行管理。
2. **桌面萌宠**：基于 Gemini 与 DeepSeek API 开发的桌面 AI Agent，具备系统状态感知与情感反馈能力。
3. **悉达多之河**：深耕复杂 Prompt 架构的内省工具，探索 Agent 在复杂业务流转中的状态机管理。
4. **指尖森林**：通过 Canvas 引擎实现的生成式交互实验，验证 AI 在视觉工程落地的可能性。
5. **产业研究**：运用自动化 SOP 处理数据清洗与回归分析，将学术理论转化为严谨的量化实证。

## 📈 部署与运行 

本站为纯静态页面，已针对 GitHub Pages 进行优化。

1.  **克隆仓库**：
    ```bash
    git clone https://github.com/bsin-ai/Sisyphus-Odyssey-web.git
    ```
2.  **环境要求**：
    * 无需任何构建步骤。
    * 建议使用支持 `backdrop-filter` 的现代浏览器（如 Chrome, Edge, Safari）。
3.  **本地预览**：
    * 通过 VS Code 的 `Live Server` 插件或直接打开 `index.html`。
